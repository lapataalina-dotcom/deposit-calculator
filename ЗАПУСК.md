Окружение: JDK 21.0.12, Maven 3.9.16, Ant 1.10.18 (`D:\programm\Apache Ant\apache-ant-1.10.18`).
Команды — для **CMD** или **PowerShell** (отличия указаны отдельно).

> Самый короткий путь: ШАГ 1 → ШАГ 2 (`download-junit.bat`) → ШАГ 3 → `run-all.bat`.
> Шаги 4–10 нужны, чтобы выполнить и показать всё по отдельности (для отчёта и защиты).

## ШАГ 2. Скачать 7 JAR-ов JUnit 5 в `lib\`

JAR-ы нужны **только Ant** (он не умеет сам тянуть зависимости). Maven и Gradle скачивают их сами.

**Вариант А (скрипт):**
```bat
cd C:\Users\mi\IdeaProjects\deposit-calculator
download-junit.bat
```
Ожидаете: 7 строк `[загрузка] ...jar`, затем список файлов в `lib\`:
```
apiguardian-api-1.1.2.jar
junit-jupiter-api-5.14.4.jar
junit-jupiter-engine-5.14.4.jar
junit-platform-commons-1.14.4.jar
junit-platform-engine-1.14.4.jar
junit-platform-launcher-1.14.4.jar
opentest4j-1.3.0.jar
```

**Вариант Б (через Maven):**
```bat
cd C:\Users\mi\IdeaProjects\deposit-calculator
mvn dependency:copy-dependencies -DoutputDirectory=lib -DincludeScope=test
```
Ожидаете `BUILD SUCCESS`. Maven положит те же 7 JAR-ов (транзитивно из `junit-jupiter`) — **и ещё** `junit-jupiter-params` (он входит в агрегатор `junit-jupiter`). Лишний JAR не мешает: он лежит в `lib\` и попадает в classpath, на работу Ant не влияет.
В PowerShell параметры с `-D` надо взять в кавычки: `mvn dependency:copy-dependencies "-DoutputDirectory=lib" "-DincludeScope=test"`.

## ШАГ 6. Ant

```bat
ant -p
ant clean
ant test
ant report
ant jar
ant run
ant all
```
Можно одной строкой в CMD: `ant -p && ant clean && ant test && ant report && ant jar && ant run && ant all`.
В **Windows PowerShell 5.1** `&&` не работает — используйте `;` (команды пойдут подряд без остановки при ошибке) или запустите `run-all.bat`.

Что ожидать:

| Команда | Ожидаемый вывод / результат |
|---|---|
| `ant -p` | Список: `all, clean, compile, compile-tests, init, jar, report, run, test` с описаниями |
| `ant clean` | `Сборочная директория очищена.`, `BUILD SUCCESSFUL`, папки `build\` нет |
| `ant test` | `Основной код скомпилирован.`, `Тестовый код скомпилирован.`, `Tests run:9, Failures:0, Aborted:0, Skipped:0`, `BUILD SUCCESSFUL` |
| `ant report` | `HTML отчёт создан в build/reports/html`, `BUILD SUCCESSFUL`; XML: `build\reports\xml\TEST-by.student.deposit.DepositCalculatorTest.xml`, HTML: `build\reports\html\index.html` |
| `ant jar` | `JAR создан.`; файл `build\jar\DepositCalculator.jar` |
| `ant run` | Печатает «Отчёт по вкладу»: итоговая сумма `1331.00 BYN`, проценты `331.00 BYN` |
| `ant all` | clean → тесты → отчёт → JAR; в конце `Ant: полная сборка завершена успешно.` и `BUILD SUCCESSFUL` |

Открыть HTML-отчёт: `start build\reports\html\index.html`

Если в консоли «кракозябры»: выполните `chcp 65001` и повторите (сам вывод `ant run` уже принудительно в UTF-8).

## ШАГ 8. HTML-отчёт Surefire

```bat
mvn surefire-report:report
```
Ожидаете `BUILD SUCCESS`; отчёт: `target\site\surefire-report.html`
```bat
start target\site\surefire-report.html
```
Почему отдельно: Surefire пишет только XML/TXT, HTML строит другой плагин (`maven-surefire-report-plugin`) **из уже готовых XML**. Поэтому сначала должен быть `mvn test` (или `verify`).

## ШАГ 9. (Опционально) Gradle Wrapper

Gradle у вас, судя по окружению, не установлен — команда `gradle wrapper` требует его **один раз** (установка: `winget install Gradle.Gradle` или `choco install gradle`, затем новый терминал).
```bat
gradle wrapper --gradle-version 9.8
gradlew.bat build
gradlew.bat run
```
Если версия 9.8 не находится — подставьте актуальную 9.x с https://gradle.org/releases/.

Ожидаете: `BUILD SUCCESSFUL`, в логе строки `DepositCalculatorTest > ... PASSED`.
Артефакты: `build\reports\tests\test\index.html`, `build\libs\deposit-calculator-1.0.0-SNAPSHOT.jar`.

Нюансы (почему файлы чуть отличаются от листингов 7–8):
- Toolchain требует JDK **17**, а у вас 21. В `settings.gradle` добавлен плагин `foojay-resolver-convention` — Gradle сам скачает JDK 17 при первой сборке (нужен интернет, ~200 МБ). Если JDK 17 уже установлена, плагин можно удалить.
- В `build.gradle` добавлена строка `testRuntimeOnly 'org.junit.platform:junit-platform-launcher:1.14.4'` — Gradle 9 без неё тесты не запускает.
- Wrapper-файлы (`gradlew`, `gradlew.bat`, `gradle\wrapper\`) нужно закоммитить в репозиторий.

## ШАГ 10. Эксперимент с падающим тестом

1. Базовая линия: `mvn clean verify` → `BUILD SUCCESS`.
2. Откройте `src\test\java\by\student\deposit\DepositCalculatorTest.java`, в методе `simpleInterest()` замените `1300.0` на `1400.0` (только там; в `totalDependsOnCapitalization()` не трогайте).
3. Запустите:
   ```bat
   mvn test
   ```
   Ожидаете:
   ```
   [ERROR] Tests run: 9, Failures: 1, Errors: 0, Skipped: 0
   [ERROR] DepositCalculatorTest.simpleInterest:... expected: <1400.0> but was: <1300.0>
   [INFO] BUILD FAILURE
   ```
   Зафиксируйте скриншот. `echo %ERRORLEVEL%` покажет `1` — именно этот ненулевой код CI считает провалом.
   (Если запустить `mvn package`/`verify`, JAR не создастся — сборка остановится на фазе `test`.)
4. Верните `1300.0`.
5. `mvn clean verify` → `BUILD SUCCESS`, `Tests run: 9, Failures: 0`.

То же на Ant: после правки `ant test` завершится `BUILD FAILED` (`haltOnFailure="true"`), JAR не будет создан.

## Типичные ошибки

| Симптом | Причина | Решение |
|---|---|---|
| `'ant' is not recognized...` / `ant: command not found` | Ant не в PATH | ШАГ 3, затем **новое** окно терминала |
| `failed to create task or type junitlauncher` | Нет `ant-junitlauncher.jar` в `ANT_HOME\lib` | ШАГ 4 |
| `NoClassDefFoundError` / `ClassNotFoundException: org.junit...` | В `lib\` не все 7 JAR-ов | `download-junit.bat`, проверьте `dir lib` |
| `Tests run: 0` | Имя тестового класса не заканчивается на `Test` (в Ant маска `**/*Test.class`; у Surefire — `*Test`, `Test*`, `*Tests`, `*TestCase`) | Переименуйте класс; в Ant проверьте, что `ant compile-tests` отработал |
| `release version 17 not supported` | Запущено на JDK < 17 | `java -version` / `javac -version` должны быть ≥ 17 |
| Кракозябры вместо кириллицы | Кодировка консоли | `chcp 65001` |
| Gradle: `No matching toolchains found` | Нет JDK 17 и нет foojay-плагина/интернета | ШАГ 9 |
| `.bat` «ничего не делает после первой команды» | В своих скриптах `ant`/`mvn` нужно вызывать как `call ant ...` | В наших `.bat` уже сделано |
